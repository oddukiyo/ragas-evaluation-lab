# RAGAS Evaluation Lab

Standalone Next.js project for demonstrating the RAGAS paper.

Includes tokenization, chunking, TF-IDF vectorization, cosine retrieval, OpenRouter API generation, and RAGAS-style evaluation.

Run locally:

```bash
npm install
npm run dev
```

Deploy on Vercel by uploading this project to a new GitHub repository and importing it in Vercel.
